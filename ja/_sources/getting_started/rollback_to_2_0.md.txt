# PME 2.0.5.xへ戻す

PME 2.1からPME 2.0.5.xへ戻す場合は、通常のアップデートとは異なり、
PME 2.1へ移行する前に書き出したJSONを使って復元します。

1. PME 2.1 Extensionをアンインストールします。
2. Blenderを終了し、もう一度起動します。
3. 以前使用していたPME 2.0.5.xのLegacy Add-onをインストールし、有効化します。
4. PME 2.1へ移行する前に書き出したJSONをImportします。

```{warning}
PME 2.1で書き出したJSONには、PME 2.0.5.xが対応していない機能が含まれる場合があります。
PME 2.1のJSONをPME 2.0.5.xへそのままImportする方法は、旧版へ戻す手順として保証されません。

この手順では移行前に保存したJSONへ戻るため、PME 2.1で追加または編集したメニューは復元されません。
```
